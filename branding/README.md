# FlatPPL branding

These assets are copies from [flatppl-theme](https://github.com/flatppl/flatppl-theme/tree/b01dabb9622722f90f029aa24195b1b1f7e229b9/assets).
The source assets remain in that repository.

| Asset | Use |
| --- | --- |
| `logo.svg` | Original squircle symbol |
| `logo-rounded.svg` | More circular squircle symbol used by the cheatsheets |
| `logo-master.svg` | Editable source art |
| `logo-original.png` | Original raster art |
| `wordmark.svg` | Standalone wordmark |
| `favicon.svg`, `favicon.ico`, PNG icons, `site.webmanifest` | Browser and app icons |
| `proposals/` | Original circle and full squircle variants |

`logo-rounded.svg` keeps the original graph and plot artwork. Only its background differs.
Its outline follows the superellipse `abs((x - 128) / 128)^2.5 + abs((y - 128) / 128)^2.5 = 1`.
This gives a squircle closer to a circle than the original badge.
